#1. What I Learned

OSI Model

7 layers of networking

Application → where protocols like HTTP and DNS work

Transport → TCP / UDP

Network → IP addressing

Protocols

TCP → reliable, connection-oriented

UDP → fast, connectionless

DNS

translates domain names to IP addresses

works on port 53

HTTP / HTTPS

HTTP → port 80

HTTPS → encrypted with TLS on port 443

#2. Networking Flow

User types google.com

↓
DNS query resolves domain to IP

↓
TCP connection established (3-way handshake)

↓
HTTP request sent to server

↓
Server responds with webpage
